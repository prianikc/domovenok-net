# ДомовёнокNET

Программа для Windows 11, которая управляет домашним роутером на OpenWrt и VPN на нём (AmneziaWG или WireGuard).
Живёт в трее, показывает скорость всего дома в реальном времени и позволяет решать, какие сайты идут через VPN.

| Значок в трее | Что значит |
|---|---|
| 🟢 зелёный | VPN работает |
| 🟡 жёлтый | выполняется команда |
| 🔴 красный | VPN выключен или не отвечает (нет рукопожатия с сервером) |
| ⚪ серый | роутер не отвечает |

- **Один клик** по значку — маленькое окно со скоростью и кнопками.
- **Двойной клик** — большое окно: «Обзор», «Списки», «Профили», «Роутер», «Сервер».
- **Правый клик** — меню: открыть, перезапустить или выключить туннель, закрыть программу.

## Возможности

- три состояния туннеля: **Выключен** (весь дом через провайдера), **Только список** (через VPN только выбранное),
  **Всё через VPN**;
- подборки сервисов (YouTube, Telegram, Discord, ИИ-сервисы и др.) с автообновлением и кнопкой «Обновить»;
- свои сайты, IP-адреса и подсети;
- профили AmneziaWG и WireGuard: файл `.conf`/`.awg` или строка `vpn://` из приложения AmneziaVPN;
- табло скорости: сколько дом качает сейчас, через VPN и напрямую, пинг до сервера;
- кнопка «Проверить» — объясняет, где обрыв: провайдер, сервер или профиль;
- перенос настроек со старой версии (VPN Tray 1.0) с резервной копией и откатом.

## Установка

1. Скачайте `DomovenokNET-…-setup.exe` со страницы [Releases](https://github.com/prianikc/domovenok-net/releases).
2. Запустите. У установщика нет платной цифровой подписи, поэтому Windows покажет синее окно
   «Windows защитила ваш компьютер». Нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**.
3. Программа сама найдёт роутер. Если на нём задан пароль root, она спросит его один раз.

Обновления программа скачивает сама и ставит, когда вы её закрываете.

## Что нужно от роутера

OpenWrt 24.10 или 25.x с пакетами `dnsmasq-full`, `kmod-amneziawg` и `amneziawg-tools`.
Программа заливает на роутер свои скрипты и примерно 1–1,5 МБ данных.
Вся логика работает на роутере, поэтому VPN и списки действуют, даже когда компьютер выключен.

## Как устроено

```
Windows (ДомовёнокNET)  --SSH по своему ключу-->  роутер OpenWrt (команда domovenok)
                                                     |
                                                     +-- туннель AmneziaWG/WireGuard --> ваш сервер
```

| Папка | Что там |
|---|---|
| `app/` | программа: Electron + TypeScript + React |
| `router/` | скрипты для роутера (пути совпадают с путями на роутере) и их тесты |
| `presets/` | каталог подборок и собственные списки, роутер скачивает их отсюда |
| `docs/superpowers/` | дизайн и план |

Где программа хранит данные: `%APPDATA%\DomovenokNET` — настройки, зашифрованный SSH-ключ, резервные копии роутера.

## Разработка

```sh
cd app
npm install
npm test               # тесты программы
npm run test:router    # тесты скриптов роутера (bats)
npm run dev            # запуск (на Windows)
npx electron-builder --win   # установщик
```

Выпуск: тег `vX.Y.Z` запускает сборку установщика в GitHub Actions и публикует его в Releases.
