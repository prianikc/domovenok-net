# «ДомовёнокNET» (бывший VPN Tray) — программа управления роутером OpenWrt и VPN

Дата: 2026-10-22. Статус: черновик дизайна, ждёт одобрения.

## Зачем

Сейчас VPN Tray — трей-программа на C# (.NET Framework), которая по SSH отдаёт команды скриптам на роутере
OpenWrt (`router/` в репозитории). Она завязана на машину автора: ключ лежит в `~/.ssh`, списки и профили
в папке `DataDir`, роутер настраивался руками.

Нужна программа под Windows 11, которую можно дать знакомому, не разбирающемуся в сетях. Она проводит
весь путь: обычный роутер → OpenWrt → роутер подключён к VPN (AmneziaWG или WireGuard на своём сервере,
поднятом через приложение AmneziaVPN) → трафик дома разделяется по спискам. Управление — дашборд
с живой скоростью всего дома. Всё ставится с нуля, никаких настроек конкретного ПК.

**Критерий успеха (слова автора):** программа работает у автора и при первой установке корректно
переносит все его текущие настройки (профили, сайты, IP). Остальное (мастер для
новичков, прошивка чужих роутеров) важно, но вторично.

## Очерёдность

Проект делится на три части; каждая заканчивается рабочей программой. Дизайн описывает все три, чтобы
архитектура сразу их учитывала. **План реализации пишется только на часть 1.**

1. **Новая программа + роутер автора.** Electron-приложение (дашборд, мини-окно, трей), три состояния
   туннеля, подборки и «Мои сайты/IP», кнопка «Проверить», обновлённые скрипты роутера,
   миграция с текущей настройки автора, профили (добавить/переключить).
2. **Сервер Amnezia.** Админский профиль → выпуск, список, переименование, отзыв клиентских профилей.
3. **Мастер для новичков.** Экран «Какой роутер нужен», поиск и определение роутера, автопрошивка
   OpenWrt (Cudy, TP-Link Archer AX23 v1), установка всего с нуля.

## Цели, не-цели, анти-цели

**Цели**
- Один установщик для Windows 11; после него ничего не нужно настраивать руками ни на ПК, ни на роутере.
- Вся логика маршрутизации живёт на роутере и работает при выключенном ПК.
- Красивый, понятный интерфейс на русском языке.

**Не-цели**
- VLESS / sing-box (есть в текущих скриптах) — **убираем**.
- Списки «напрямую» (сайты, IP, порты, программы-источники вроде qBittorrent) — **убираем полностью**.
- Сканирование QR-кодов в программе — не нужно (только показ).
- Роутеры, на которые нельзя поставить OpenWrt (Keenetic и т. п.) — не поддерживаются, программа честно
  об этом говорит.
- Платная подпись кода — пока нет.
- Автоматический переход «всё напрямую», если туннель умер — **не делать** (решение автора).

**Анти-цели (провал, даже если «работает»)**
- Миграция роутера автора теряет его профили, сайты или IP, или ломает интернет дома без
  возможности отката.
- Программа требует от человека правки файлов, командной строки или знаний про SSH.
- Прошивка «кирпичит» роутер из поддерживаемого списка.

## Технологии (решение Claude, автор согласился)

- **Electron + TypeScript + React**, установщик через electron-builder (NSIS), автообновление из
  **GitHub Releases** этого репозитория (electron-updater).
- Установщик **не подписан**: при первом запуске Windows SmartScreen покажет «Windows защитила ваш
  компьютер». На странице загрузки и в README — картинка «Подробнее → Выполнить в любом случае».
- SSH к роутеру и серверу — библиотека `ssh2` в main-процессе; никакого внешнего `ssh.exe`.
- Автор знает TS/JS и будет поддерживать код сам — код должен быть читаемым, без экзотики.

## Интерфейс

Макеты согласованы в браузере (файлы в `.superpowers/brainstorm/…/content/`:
`dashboard-layout-v6.html`, `tray-modes-v2.html`). Тёмная тема.

### Три способа открыть из трея
- **Двойной клик левой кнопкой** → большое окно (дашборд). Окно узкое, ~640 px по ширине.
- **Одиночный клик левой кнопкой** → мини-окно над треем (~300 px): статус-плашка, крупная цифра
  загрузки, отдача, маленький график с двумя линиями, плитки «Режим» и «Пинг», кнопки «Режим ⇄»,
  «Перезапуск», «Выключить». **В правом верхнем углу — крестик (закрыть мини-окно)**, не «развернуть».
  Мини-окно закрывается и при потере фокуса (решение Claude).
- **Правый клик** → меню: «Открыть», «Перезапустить туннель», «Выключить туннель», «Закрыть программу».
- Значок в трее по цвету: зелёный — туннель работает; жёлтый — идёт команда; красный — туннель включён,
  но рукопожатия нет, либо туннель выключен; серый — роутер не отвечает. (Различие «выключен» и
  «сломан» — в подсказке значка; цвет для выключенного туннеля — на усмотрение строителя, но сломанный
  обязан быть красным.)

### Большое окно
Навигация сверху: **Обзор · Списки · Профили · Роутер · Сервер**.

**Обзор (вариант C из макетов):**
- Плашка статуса: «● Защищено · Нидерланды · AmneziaWG» (страна — по IP сервера или из имени профиля,
  на усмотрение строителя).
- По центру огромная цифра скорости загрузки (Мбит/с), под ней отдельной строкой отдача (↑, цвет
  сине-сиреневый `#8b9cf7`, не розовый).
- График за последние 60 с: **две линии без заливки** — «через VPN» (мягкий зелёный `#6cc58a`) и
  «напрямую» (синий `#58a6ff`). Контур замкнутой фигуры (бока/низ) не рисовать — только линии.
- Плитки: Режим · Через VPN (Мбит/с) · Напрямую (Мбит/с) · Пинг до сервера.
- Переключатель состояния туннеля (три состояния, см. ниже) и кнопка «Проверить».

### Табло скорости
- Показывает **реальную скорость всего дома** по счётчикам роутера, обновление раз в секунду, плавно.
- Источник — счётчики интерфейсов (`/proc/net/dev`: WAN и интерфейс туннеля). Через VPN = трафик
  интерфейса туннеля; напрямую ≈ трафик WAN минус трафик туннеля с поправкой на накладные расходы
  инкапсуляции. Точный способ (вычитание, счётчики nft и т. п.) — на усмотрение строителя; требование:
  «примерно, но достаточно точно» и динамично.
- Не опрашивать роутер новым SSH-подключением каждую секунду: одно долгоживущее соединение/поток.
- Пинг до сервера — периодический ICMP с роутера на публичный адрес сервера (раз в несколько секунд).

## Маршрутизация

### Три состояния туннеля
| Состояние | Поведение |
|---|---|
| **Выключен** | весь дом через провайдера, списки не работают |
| **Только список** | всё через провайдера; через VPN — включённые подборки + «Мои сайты/IP» |
| **Всё через VPN** | весь дом через VPN, **без исключений** |

Скрытые служебные исключения, которые программа ставит сама и не показывает: NTP (`udp 123`) напрямую
(иначе после перезагрузки туннель не поднимется), пакеты самого туннеля к серверу — напрямую (fwmark,
как сейчас), DNS роутера (`1.1.1.1`, `8.8.8.8` и т. п.) — через туннель, чтобы провайдер не подменял
ответы.

### Подборки (сервисы)
- Галочка на сервис: YouTube, Telegram, Discord, Instagram/Meta, ИИ-сервисы и т. д. Внутри подборки —
  и домены, и IP-подсети. Под галочкой показываются примеры записей: «youtube.com, googlevideo.com,
  ytimg.com… и ещё 12».
- Источники: открытые списки `itdoginfo/allow-domains` на GitHub (по сервисам, плюс общий список
  «заблокированное в РФ»), официальные списки сервисов (Telegram `core.telegram.org/resources/cidr.txt`).
  Подборки, которых нет во внешних источниках (например, Anthropic/Claude, JetBrains — есть у автора),
  — **собственные подборки, хранящиеся в этом репозитории** и скачиваемые оттуда же.
- Обновление: автоматически по расписанию **и** кнопка «Обновить». Скачивает роутер сам (работает без
  ПК); программа может инициировать.
- Если источник недоступен — оставить последнюю рабочую версию, не очищать.

### Мои сайты / IP
- Ручной ввод доменов (домен включает поддомены). Под «Дополнительно» — IP или подсеть (`1.2.3.4`,
  `1.2.3.0/24`). Удаление из списка. Применение на роутере без разрыва соединений (как сейчас).
- Предупреждение: если в браузере включён «безопасный DNS» (DoH), списки сайтов на этом устройстве не
  работают.

### Устройства — убрано
Режим «корп. VPN» и раздел «Устройства» **убраны** (решение автора, 2026-10-22): подсети подборок и так
идут через туннель для всех устройств, отдельный режим ничего не добавлял. Правило одно для всего дома:
через туннель — домены и подсети включённых подборок и «Мои сайты/IP»; остальное — через провайдера.

## Сторож и диагностика
- **Автоматически проверяется только рукопожатие** WireGuard/AmneziaWG (`latest-handshakes`). Нет свежего
  рукопожатия → значок красный + уведомление Windows «VPN не отвечает». Трафик напрямую **не пускать**.
- **Исключение — DNS в режиме «Только список» (решение автора).** Пока рукопожатия нет, DNS-запросы
  роутера временно идут через провайдера, чтобы дом не терял весь интернет; сайты из списка при этом
  не открываются (их трафик по-прежнему уходит в мёртвый туннель). Когда рукопожатие вернулось — DNS
  снова через туннель. В режиме «Всё через VPN» дом без интернета, пока туннель мёртв (решение автора).
- Если переключение профиля не удалось и откат на предыдущий тоже не удался, туннель остаётся
  включённым в состоянии «не работает» (красный), а не выключается, как в старом `wgsw` (решение
  Claude, следует из «напрямую не пускать»).
- Внешние «проверочные» адреса (94.140.14.14, 76.76.2.0, 208.67.220.220) — **убрать**.
- **Кнопка «Проверить»** — ручная диагностика одной кнопкой: рукопожатие; пинг своего сервера внутри
  туннеля (внутренний адрес сервера Amnezia, обычно `10.8.1.1`); DNS через туннель; связь роутера
  с провайдером; доступность сервера напрямую. Итог — человеческим языком, с указанием, где обрыв:
  роутер / провайдер / сервер / профиль.

## Подключение программы к роутеру
- Программа заходит на роутер по своему SSH-ключу. Если ключа нет (новая установка, второй ПК,
  переустановка Windows), программа один раз спрашивает пароль root (на чистой OpenWrt пароля может не
  быть — тогда без вопроса), прописывает свой ключ и дальше пароль не нужен (решение Claude).
- При миграции у автора: сначала пробуется ключ старой программы (`C:\RouterVPN\router_key`, путь из
  старого `config.ini`, если он найден), иначе — пароль, как выше.

## Хранение
- **На роутере** — всё, что нужно для работы: профили, выбранные подборки, «Мои сайты/IP»,
  состояние. Программа только показывает и меняет. Вторая установка программы в той же сети видит те же
  настройки.
- Объём на роутере ~1–1,5 МБ (скрипты ~30 КБ, AmneziaWG ~0,3–0,5 МБ, `dnsmasq-full` ~0,2 МБ, подборки
  до ~0,5 МБ). Перед установкой программа проверяет свободное место и показывает «Понадобится ~1,5 МБ,
  свободно N МБ». Если мало — предлагает держать скачиваемые подборки в RAM (`/tmp`) и перекачивать после
  загрузки.
- **На ПК** (`%APPDATA%`): адрес роутера, SSH-ключ программы, данные доступа к серверу (часть 2).
  Секреты — через Electron `safeStorage` (DPAPI). Программа генерирует свой SSH-ключ и прописывает его на
  роутер; на чужие ключи из `~/.ssh` не опирается (кроме одноразового чтения при миграции).

## Профили VPN
- Типы: AmneziaWG (`.awg`/конфиг Amnezia) и WireGuard (`.conf`). Профили хранятся на роутере.
- Добавить профиль: перетащить файл, выбрать файл или вставить строку подключения из буфера
  (`vpn://…` формата AmneziaVPN). Переключение профилей с откатом на предыдущий, если новый не поднялся
  (как сейчас в `wgsw use`).

## Часть 1: миграция роутера автора

**Роутер автора (проверено по SSH 2026-10-22, только чтение):** Cudy WR3000S v1, `mediatek/filogic`
(aarch64), **OpenWrt 25.12.5 — пакетный менеджер `apk`, не `opkg`**; ядро 6.12; RAM ~240 МБ, свободно
на `/overlay` ~37 МБ. Уже стоят `dnsmasq-full`, `kmod-amneziawg`, `amneziawg-tools`,
`luci-proto-amneziawg`, `wireguard-tools`, `nftables-json`, `ca-bundle`. Профили: 6 × `.conf`
(WireGuard через UCI `network.wg0`) и 1 × `.awg`; режим `list`; в cron — `blackbox`.
**IPv6 дома нет**: глобальных IPv6-адресов нет, RA и DHCPv6 на LAN выключены. Программа работает
только с IPv4; если на роутере обнаружен активный IPv6 — предупреждать (поддержка IPv6 — не цель).
Программа должна поддерживать и `apk` (OpenWrt 25.x), и `opkg` (24.10) — для части 3.

На роутере есть то, чего нет в репозитории: `ru-routes.txt`(+`.bak`), `update-ru.sh`, `direct-extra.txt`
(пустой), каталог `disabled/` — старые остатки, удаляются при миграции (с резервной копией). Интерфейс
`ocvpn` (OpenConnect, выключен, `auto=0`) — **не трогать**: миграция не изменяет ничего, чего не знает.

При первом подключении к роутеру со старыми скриптами (`/usr/bin/wgsw`, `/etc/vpnsplit/`):
1. Сделать резервную копию старой настройки (файлы скриптов, списков, профилей, затронутые UCI-секции)
   и сохранить её на ПК; дать кнопку «откатить».
2. Перенести профили `/etc/wg-profiles/*.awg`, `*.conf`. Профили `.vless` — не переносятся,
   предупредить заранее.
3. Перенести `tunnel-domains.txt`: домены, покрываемые подборками, → включить соответствующие подборки;
   остальное → «Мои сайты». Аналогично `tunnel-ips.txt` → подборки (Telegram) / «Мои IP»; служебные
   адреса (DNS, проверочные) не переносить как пользовательские.
4. `work-ips.txt` → подборки (если подсеть в них есть) или «Мои IP»; `work-pc.txt` — удаляется.
5. Текущий режим (`full`/`list`) и включённость туннеля сохранить.
6. Списки «напрямую», `blackbox`, `vps-check`, VLESS — удалить, предупредив заранее, что именно
   исчезнет.
7. Показать итог миграции: что перенесено, что удалено.
8. Старая программа VPN Tray (C#): новая установка должна её остановить и убрать из автозапуска
   (решение Claude). Из её `config.ini` один раз прочитать адрес роутера и путь к ключу, чтобы
   подключиться без вопросов.

## Часть 2: сервер Amnezia
- **Обычный профиль** — роутер просто подключается.
- **Админский профиль** — «полный доступ» из приложения AmneziaVPN (данные SSH к серверу). С ним
  программа сама заходит на сервер.
- Найти контейнер AmneziaWG в Docker и **определить реальный порт** (у автора руками сменён на 443;
  у других может быть стандартный) — из настроек контейнера, не полагаясь на стандартные значения.
- Выпуск клиентских профилей; в т. ч. автоматически выпустить отдельный профиль для роутера.
- Выдача профиля тремя способами: файл конфига, строка `vpn://…` в буфер обмена, QR-код на экране.
- Список выданных профилей: имя, когда последний раз подключался; переименование; отзыв доступа.
  Совместимость с приложением AmneziaVPN (чтобы его список клиентов и наш не расходились) —
  желательна, строителю проверить, где Amnezia хранит список клиентов в контейнере.

## Часть 3: мастер для новичков
- **Экран «Какой роутер нужен»**: кратко — программа работает только с роутерами, где OpenWrt уже стоит
  или её можно поставить. Три группы:
  1. Уже с OpenWrt: Routerich AX3000, GL.iNet Beryl AX / Flint 2, прошитые Xiaomi AX3000T
     с маркетплейсов, любой роутер с OpenWrt.
  2. Программа прошьёт сама: **Cudy** (WR3000S/TR3000 — промежуточная прошивка Cudy, затем OpenWrt)
     и **TP-Link Archer AX23 v1** (`factory.bin` через «Обновление прошивки»; **v2 не поддерживается**).
  3. Сложные — только ссылка на видео/статью: Xiaomi AX3000T (XMiR-Patcher), Xiaomi AX6S, Mercusys
     MR90X и т. п.
  Keenetic и подобные — «не подходит».
- **Автоматическая прошивка — только там, где это безопасно и просто через родной веб-интерфейс.**
  Начинаем с Cudy и TP-Link AX23 v1; остальные — позже. Для всего прочего — ссылка на инструкцию.
- Ход мастера:
  1. Найти роутер в сети (шлюз по умолчанию).
  2. Если OpenWrt — узнать точную модель (`ubus call system board`) и сверить с каталогом
     `downloads.openwrt.org` (те же данные, что в Firmware Selector).
  3. Если заводская прошивка — догадка о модели по веб-интерфейсу («Похоже, это Cudy WR3000S»),
     человек подтверждает или выбирает из списка; ревизию сверяет по наклейке (подсказка с картинкой).
  4. Предупредить: заводские настройки сотрутся, интернет пропадёт на несколько минут.
  5. Скачать нужные файлы с официальных сайтов (Cudy, openwrt.org), прошить.
  6. GL.iNet и Routerich — перешить на чистую OpenWrt (решение Claude: чтобы скрипты работали
     одинаково).
  7. Поставить AmneziaWG (пакеты под версию OpenWrt и архитектуру), `dnsmasq-full`; проверить место.
  8. Залить скрипты, прописать SSH-ключ программы, задать пароль root.
  9. Включить Wi-Fi с именем и паролем, введёнными в мастере.
  10. Вставить профиль VPN (обычный или админский → выпустить профиль роутера).
  11. Открыть главный экран.

## Скрипты на роутере
Текущие скрипты (`router/`) — основа. Изменения:
- Убрать VLESS/sing-box, списки «напрямую» (`direct-*`), `direct-src`, `blackbox`, `vps-check`,
  внешние проверочные адреса, автоматический переход «напрямую» (`fb_*`).
- Сторож (`probe`, `wait_up`, NTP-хук) переделать на рукопожатие.
- Режим `full` — без исключений, кроме служебных.
- Новое: подборки (скачивание, обновление по расписанию), поток
  счётчиков для табло, диагностика для кнопки «Проверить», машиночитаемый вывод (JSON) для программы.
- Структура файлов, имена команд, формат хранения — на усмотрение строителя; требование — устанавливать
  и обновлять их программа должна сама.

## Репозиторий
- Репозиторий на GitHub будет **публичным** (решение автора): из него обновляется программа
  (GitHub Releases) и роутер скачивает собственные подборки. Репозиторий: `prianikc/domovenok-net` (пока приватный, публичным станет после уборки личных данных) —
  в коде держать его одной настройкой.
- Перед публикацией убрать из репозитория личные данные автора (IP рабочего ПК в `work-pc.txt` и т. п.;
  примеры списков заменить нейтральными).

## Оставлено строителю
